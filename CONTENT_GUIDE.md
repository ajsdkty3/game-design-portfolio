# Portfolio Content Guide

Use this as the checklist for the material you send me next.

## 1. Basic Identity

- full name
- preferred title line
- email
- GitHub link
- LinkedIn link
- itch.io link
- any additional portfolio or blog link

## 2. Homepage Intro

Send me:

- a 2-4 sentence self introduction
- what kind of game designer you want to present yourself as
- the programs or schools you are targeting
- a short sentence about your design interests

## 3. Featured Projects

For each main project, send:

- project title
- one-sentence pitch
- genre
- platform
- year
- team size
- your role
- tools used
- 3-5 design goals
- key mechanics
- biggest design challenge
- what changed after testing
- final result or takeaway
- project link if any
- video link if any
- 3-8 screenshots

## 4. Design Studies

Good candidates:

- level design analysis
- systems design experiment
- paper prototype
- board game study
- onboarding / UX breakdown
- research notes
- jam prototype

For each one, send:

- title
- topic
- goal
- method
- what you learned
- images, diagrams, or GIFs

## 5. CV Page

Send me:

- education
- expected graduation date
- relevant coursework
- internships or studio experience
- collaborative project experience
- software tools
- design strengths
- languages if you want them shown

## 6. Files and Assets

Best asset types:

- screenshots: `.png` or `.jpg`
- diagrams: `.png`
- videos: YouTube or Vimeo links
- resume: `.pdf`

Suggested organization:

- `public/img/projects/`
- `public/img/profile/`
- `public/d/`

## 7. Application Positioning

Tell me which direction you want the portfolio to emphasize:

- level design
- systems design
- gameplay design
- narrative design
- technical design
- generalist game design

Once you send the first batch of material, I can start replacing the placeholder content directly in the site.
